## 🔧 Personalización

### Cambiar el número de WhatsApp

Busca `977679888` en los archivos y reemplázalo por tu número (con el código de país: **+51** para Perú)

### Cambiar colores

En `styles.css`, busca `:root` y modifica:
```css
--primary-color: #0088cc;        /* Azul principal */
--secondary-color: #00bcd4;      /* Turquesa */
--accent-color: #4db8a8;         /* Verde suave */
```

### Cambiar texto

En `index.html` puedes editar cualquier texto, títulos, descripciones, etc.

### Agregar más servicios

Duplica una tarjeta de servicio en la sección "Servicios de enfermería" y personalízala.
